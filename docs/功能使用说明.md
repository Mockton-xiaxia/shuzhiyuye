# 数智渔业平台 · 功能使用说明

> 面向演示、培训与二次开发的**操作手册**。  
> 默认演示账号见下表，启动方式见 [README.md](../README.md)。

## 1. 登录与门户

### 1.1 启动系统

```powershell
# 终端 1：后端
cd backend
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

# 终端 2：前端
cd frontend/apps/admin
npm install
npm run dev
```

浏览器访问：**http://127.0.0.1:5173**

### 1.2 演示账号

| 账号 | 密码 | 门户 | 说明 |
|------|------|------|------|
| `gov_admin` | `123456` | 区县 GOV | 监管侧：审核、备案、统计 |
| `ent_admin` | `123456` | 企业 ENT | 生产侧：养殖、仓储、销售 |

登录后系统自动识别门户：区县账号进入 `/gov/*`，企业账号进入 `/ent/*`。

### 1.3 界面布局

- **左侧菜单**：按模块分组，点击切换功能页
- **顶栏**：当前页面标题与登录用户
- **内容区**：列表（CrudPage）、工作台、地图（GIS）、大屏等

## 2. 区县监管门户（GOV）

### 2.1 工作台

路径：`/gov/workbench`

- 展示待办数量：质量整改、标识审核、尾水备案等
- 快捷入口可一键跳转到对应业务页

![区县工作台](screenshots/01-gov-workbench.png?v=20260726)

**常用操作**

1. 登录 `gov_admin` → 进入工作台
2. 查看待办卡片数字
3. 点击「进入」跳转到具体流程页处理

### 2.2 领导驾驶舱

路径：`/gov/cockpit`

- 大屏展示：主体数量、塘口面积、尾水达标率、抽检合格率
- 区域分布、趋势图表（ECharts）
- 适合投影演示，数据来自种子数据

![领导驾驶舱](screenshots/02-gov-cockpit.png?v=20260726)

### 2.3 质量安全

#### 质量抽检

路径：`/gov/quality/inspections`

| 操作 | 步骤 |
|------|------|
| 新建抽检 | 点击「新建」→ 填写批次、企业、检测机构 → 保存 |
| 查看结果 | 列表点击「查看」 |
| 发起整改 | 对不合格记录进入整改流程 |

![政策管理](screenshots/04-quality-policy.png?v=20260726)

#### 质量整改（流程页）

路径：`/gov/quality/rectifications`

状态流转：**下发 → 企业接收/回复 → 区县复核 → 关闭**

- 区县：下发整改单、复核企业回复
- 企业：在 ENT 门户接收并回复（`/ent/quality/rectifications`）
- 此页为流程操作，**非行内表格编辑**

#### 标识审核

路径：`/gov/trace/applies`

| 状态 | 区县操作 |
|------|----------|
| 待审核 | 点击「审核」→ 通过或驳回 |
| 已通过 | 可进入分发环节 |
| 已分发 | 只读查看 |

![标识统计查询](screenshots/05-trace-stats.png?v=20260726)

### 2.4 尾水监管

#### 尾水排放计划

路径：`/gov/effluent/plans`

| 状态 | 说明 | 可操作 |
|------|------|--------|
| 草稿 DRAFT | 企业或区县新建 | **编辑**、提交 |
| 已驳回 REJECTED | 审核未通过 | **编辑**后重新提交 |
| 已备案 | 审核通过 | 只读查看 |

> 截图见 [SCREENSHOTS.md](SCREENSHOTS.md)（尾水计划等流程页可按上述步骤操作，暂无单独截图）

**编辑草稿示例**

1. 列表中找到状态为「草稿」或「已驳回」的记录
2. 点击「编辑」打开表单
3. 修改排放水域、计划排放量等字段
4. 保存后可选「提交」进入备案流程

### 2.5 主体与 GIS

#### 养殖主体

路径：`/gov/party/enterprises`（区县列表）  
企业自维护：`/ent/party/self`（企业编辑自家主体）

- 深表单：基本信息、养殖品种明细、证照附件
- 区县可维护全部主体；企业仅维护自身

> 主体深表单操作见菜单「养殖主体」，截图见 [SCREENSHOTS.md](SCREENSHOTS.md)

#### GIS 塘口

路径：

- 采集：`/gov/party/gis-collect` 或企业侧采集页
- 审核：`/gov/party/gis-audit`
- 统计：`/gov/party/gis-stats`

| 功能 | 说明 |
|------|------|
| 养殖区测绘 | 在地图上绘制多边形塘口 |
| 尾水区/出水口 | 分别测绘尾水区与出水点 |
| 导入 GeoJSON | 批量导入塘口几何 |
| 提交审核 | 采集完成后提交，区县在审核页通过/驳回 |

![GIS 塘口](screenshots/03-gis-pond-collect.png?v=20260726)

### 2.6 用户管理

路径：`/gov/party/users`

- 新增/编辑区县与企业用户
- 字段：用户名、姓名、角色、所属门户

> 用户维护见菜单「用户管理」，完整截图索引见 [SCREENSHOTS.md](SCREENSHOTS.md)

### 2.7 其他 GOV 模块（概要）

| 模块 | 典型路径 | 说明 |
|------|----------|------|
| 政策管理 | `/gov/quality/policies` | 政策法规 CRUD |
| 检测机构 | `/gov/quality/agencies` | 机构名录维护 |
| 排放水域 | `/gov/effluent/waters` | 水域名录 |
| 巡检/调度 | `/gov/effluent/*` | 尾水巡检与指挥 |
| 统计报表 | 各模块 stats 页 | 多为只读统计 |

## 3. 企业生产门户（ENT）

### 3.1 企业工作台

路径：`/ent/workbench`

- 在养批次、待出塘、库存预警、物联告警概览
- 待办列表快速跳转

> 企业端界面与 GOV 类似，完整截图见 [SCREENSHOTS.md](SCREENSHOTS.md)

### 3.2 养殖生产

| 功能 | 路径 | 操作要点 |
|------|------|----------|
| 养殖批次 | `/ent/breeding/batches` | 新建批次、记录投苗与出塘计划 |
| 农事记录 | `/ent/breeding/farm-works` | 日常农事登记 |
| 休药期 | 出塘前系统校验 | 未过休药期会提示拦截 |

### 3.3 投入品与仓储

| 功能 | 路径 |
|------|------|
| 投入品入库 | `/ent/supplies/inbound` |
| 供应商 | `/ent/supplies/suppliers` |
| 仓库/库存 | `/ent/warehouse/*` |

列表页通用操作：**查询 → 新建 → 编辑 → 保存**（白名单内的 API 支持 PUT）。

### 3.4 销售与流通

- **销售订单**：状态流（待确认 → 履约 → 完成）
- **客户/合同**：`/ent/ledger/customers`、`contracts`
- **手工记账**：`/ent/ledger/entries`

### 3.5 标识与追溯

- 企业发起标识申请：`/ent/trace/applies`
- 区县审核通过后进入分发
- 申请状态可在企业侧跟踪

### 3.6 物联监测

路径：`/ent/iot/*`

- 水质、尾水、气象等监测页为**只读展示**（演示数据）
- 设备规则、告警确认等可编辑页见菜单具体项

## 4. 页面类型与编辑规则

系统页面分为四类，操作方式不同：

| 类型 | 特征 | 如何修改数据 |
|------|------|--------------|
| **CRUD 列表** | 带「新建/编辑/删除」 | 表单保存，走专用 PUT 或 `feature/update` |
| **流程页** | 整改、标识、订单等 | 点「审核/提交/通过」等按钮，改状态 |
| **只读页** | 统计、监测大屏 | 仅查看，无编辑按钮 |
| **GIS/主体** | 地图或深表单 | 地图绘制或分 Tab 表单保存 |

### 4.1 如何判断能否编辑？

- 列表行有「编辑」链接 → 可改
- 仅「查看/审核」→ 流程或只读
- 尾水计划：**草稿/已驳回** 可编辑，其他状态只读

### 4.2 通用编辑兜底

未单独实现 PUT 的字段，后端 `PUT /api/v1/fill/feature/update` 可按 `feature` + `id` + 字段名更新（见 `docs/API.md`）。

## 6. 常见问题

### Q1：登录后菜单很少/404？

确认账号门户是否正确：区县用 `gov_admin`，企业用 `ent_admin`。不要混用路径前缀。

### Q2：点击编辑没反应或 405？

该页可能为只读或流程页。查阅 `frontend/apps/admin/src/catalog/features.json` 中 `readonly` 标记。

### Q3：尾水计划无法编辑？

仅 **草稿（DRAFT）** 和 **已驳回（REJECTED）** 状态显示「编辑」按钮。

### Q4：如何重置演示数据？

删除 `backend/data/app.db` 后重启后端，种子脚本会重新初始化。

### Q5：生产环境要注意什么？

见 `docs/DEPLOY.md`：修改 `JWT_SECRET`、换 PostgreSQL、配置 CORS 与 HTTPS。

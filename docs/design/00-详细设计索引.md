### 全局约定（所有表/接口通用）

**公共字段（业务表默认带）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| project_id | BIGINT | 试点项目，可空（平台级数据为空） |
| enterprise_id | BIGINT | 企业，可空（区县级数据为空） |
| region_id | BIGINT | 行政区划，可空 |
| created_by | BIGINT | 创建人 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_by | BIGINT | 更新人 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| deleted | SMALLINT | 0 正常 / 1 删除（逻辑删） |
| remark | VARCHAR(500) | 备注 |

**统一响应：**

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "..."
}
```

**分页请求：** `page`（从1）、`size`（默认20，最大100）  
**分页响应：** `{ list, page, size, total }`
